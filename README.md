## Cómo ejecutar localmente

1. Instalar Node.js.
2. Abrir una terminal en esta carpeta.
3. Ejecutar:

```bash
npm install
npm run dev
```

## Cómo publicar en Vercel

1. Crear una cuenta en https://vercel.com
2. Crear un nuevo proyecto.
3. Subir este proyecto o conectarlo con GitHub.
4. Framework: Vite.
5. Build command: npm run build.
6. Output directory: dist.
7. Publicar.
